Corrections

Packs are fixed in GitHub's own editor, one file per pack. Every commit is checked before it goes live. If a check fails, nothing is deployed and the site stays as it was.

How

  1. Open the pack below. GitHub asks you to sign in.
  2. Search the file (Cmd+F) for the stop id, such as bad-ends-04. Detours end in d1, d2.
  3. Change only the words between the quotation marks. Leave the quotes, commas and brackets alone.
  4. Commit straight to main with a one-line message saying what you fixed.
  5. Watch the run on the Actions tab. Green means it's live a few minutes later. Red means nothing changed; the run says which check failed.

The fields people correct

title
The stop's name in the app.
story.headline
The headline on the story card.
story.card_text
The story. If you change a fact, change story.narration_script (read aloud) and the matching fact_ledger claim too.
story.look_now
The LOOK NOW line.
riddle.lines
The four riddle lines.
riddle.hint_1, riddle.hint_2
The two hints.
answer.accepted
Spellings the app accepts. Add the one a player typed.
walk_from_previous.directions
Directions from the stop before.
route_entries
Directions for short cuts and other routes, by route and stop.
sources
At the end of the file: title, url, date. Stops point at them by id (s1, s2 ...).
